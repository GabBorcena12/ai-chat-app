AIChatApp Docker Guide
======================

This guide shows how to build and run the AIChatApp projects (Core, API, Console) in Docker on a local Windows machine.

Prerequisites
-------------
- Docker Desktop installed and running on Windows
- Windows OS compatible with NanoServer 1809 containers
- .NET 9 projects: AIChatApp.Core, AIChatApp.API, AIChatApp.Console
- Command prompt or PowerShell

Dockerfile Location
------------------
C:\Users\gabri\source\repos\AIChatApp\AIChatApp.Core\Docker\Dockerfile

Step 1: Open terminal in repo root
----------------------------------
cd C:\Users\gabri\source\repos\AIChatApp

> Build context must be the repo root so Docker can access all project files.

Step 2: Build Docker Images
---------------------------

1. Core Library (default):
docker build -f AIChatApp.Core\Docker\Dockerfile -t aichatapp:core .

2. API Project:
docker build -f AIChatApp.Core\Docker\Dockerfile -t aichatapp:api --build-arg PROJECT_TO_BUILD=AIChatApp.API .

3. Console Project:
docker build -f AIChatApp.Core\Docker\Dockerfile -t aichatapp:console --build-arg PROJECT_TO_BUILD=AIChatApp.Console .

Step 3: Run Docker Containers
-----------------------------

1. Run Core Library:
docker run -it --rm aichatapp:core

2. Run API Project:
docker run -p 5157:80 -it --rm aichatapp:api

> -p 5157:80 maps container port 80 to host port 5157.

3. Run Console Project:
docker run -it --rm aichatapp:console

Step 4: Clean up Docker Images (Optional)
-----------------------------------------
docker image rm aichatapp:core
docker image rm aichatapp:api
docker image rm aichatapp:console

Tips
----
- Use --build-arg PROJECT_TO_BUILD=<ProjectName> to switch projects without changing the Dockerfile.
- Make sure Docker Desktop is running in Windows container mode (NanoServer images are Windows-based).
- If ports conflict, change the host port in the -p argument.
